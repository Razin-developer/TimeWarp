## 🔥 epic features i coded:
- **sidepanel slider**: scrub through history like a youtube video progress bar (fr fr it's so smooth).
- **autoplay slideshow**: automatically plays website history month-by-month while u sit back and eat snacks.
- **visual diff inspector**: compare old vs new html code side-by-side with epic color highlighting.
- **minimap navigator**: click lines on a minimap to scroll right to where stuff changed!
- **bookmark tags**: save your fave dates and tag them like `#retro` or `#nostalgia`.
- **share qr codes**: scan a qr code to open the archived page on ur phone instantly!
- **insane cache speeds**: uses indexeddb + gzip compression so pages load in literally 0ms.
